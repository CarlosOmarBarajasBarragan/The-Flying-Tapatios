# The-Flying-Tapatios

Cafe ITESO is a shared case-study project for the **Software Requirements Engineering** course at ITESO made by the Flying Tapatios.

## Project Overview

Cafe ITESO is a centralized digital food-ordering system for ITESO cafeterias that improves the way members of the campus community discover, order, pay for, and collect food.

## Purpose

The project explores how a digital platform could:

- Reduce unnecessary waiting
- Improve order management.
