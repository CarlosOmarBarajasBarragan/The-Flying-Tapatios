# CafeIteso - Project Context

## Project Overview

CafeIteso is an internal app for cafeteria's establishments at ITESO. 

The platform is intended to help students, professors, and staff order their food previously so they have time to eat between classes.

## Business Opportunity

Many persons of the iteso community avoid eating in campus due to the long lines at the cafeteria restaurants.

With CafeIteso you can order your food previously so you can pick up your food after class and you can make the most of your time.

## Target Community

Every iteso community member:
- Professors
- Students
- Iteso staff
- Graduated students

## Sponsor

The project sponsor is:

**Mayra Martínez**, Cafeterias Supervisor

The sponsor provides the access with cafeteria restaurants and also wants to improve the sales in the cafeteria.

## Current Functional Epics

The project currently considers the following functional areas.

### 1. User account management and authentication

Functionality related to user access, identity, participation in the platform, and account-related capabilities.

### 2. Menu Updates

Functionality that let's business modify their menus in things like availability.

### 3. Food item search and discovery

Functionality made so the user can search in less than 5 minutes.

### 4. Order placement

Functionality made so the user can edit freely their order with certain indications like allergies, if it's take out.

### 5. Order fulfillment

Functionality that let's the user know an estimated time for food preparation. As well as how the process will be for the staff.

### 6. Payment and transaction handling

How is the payment received and even the money return if the order couldn't be processed.

### 7. Alerts and notifications

Functionality so the user receives alerts depending on the status of their order. As well as for the cafeteria staff.

### 8. Analytics and service review

Functionality so the users can leave reviews and the vendors can have stats.
